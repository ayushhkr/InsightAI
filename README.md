# InsightAI

### AI-Powered Data Analytics & Revenue Intelligence

InsightAI is an interactive AI-powered analytics workspace that allows users to upload CSV datasets, explore their data using natural language, automatically generate visualizations and insights, and detect unusual patterns using machine learning.

The goal is to make data analysis accessible without requiring users to write SQL, Python, or complex analytical queries.

---

## 🚀 Features

### 📊 Automatic Dataset Profiling
Upload any CSV dataset and InsightAI automatically provides:

- Dataset dimensions
- Column information and data types
- Missing-value analysis
- Duplicate-row detection
- Statistical summaries
- Dataset preview

### 💬 Ask Your Data

Users can ask questions about their dataset using natural language.

For example:

> "Which region generated the highest total profit?"

InsightAI converts the question into a structured analysis plan, executes the analysis against the dataframe, generates a visualization, and provides an AI-powered explanation.

### 📈 Automatic Visualizations

InsightAI generates interactive Plotly visualizations based on the requested analysis.

Supported analytical operations include:

- Grouping and aggregation
- Filtering
- Correlation analysis
- Trend analysis
- Descriptive statistics

### 🤖 AI-Generated Insights

After an analysis is executed, the LLM converts the numerical results into understandable business insights and recommendations.

This creates a pipeline of:

**Question → Analysis Plan → Data Analysis → Visualization → AI Insight**

### 🔎 Machine Learning Anomaly Detection

InsightAI uses **Isolation Forest** from scikit-learn to identify unusual numerical patterns in the dataset.

The system:

1. Identifies numerical features
2. Handles missing numerical values
3. Applies Isolation Forest
4. Identifies anomalous records
5. Displays the flagged records and model information

### 🧠 AI Anomaly Explanation

Machine learning identifies unusual records, while the LLM explains the findings in natural language.

This creates a:

**ML Detection → AI Explanation**

pipeline.

The explanation is evidence-grounded and avoids claiming a real-world cause that cannot be established from the available data.

### 💬 Conversational Anomaly Investigation

Users can ask follow-up questions about detected anomalies, such as:

> "Why was row 13 flagged?"

or

> "Why are all these rows anomalous?"

The AI answers using the anomaly evidence generated by the machine-learning pipeline.

### 📄 Downloadable Analysis Report

Users can download a complete workspace report containing the available:

- Dataset profile
- Analysis results
- AI insights
- Anomaly findings

This makes the analysis easier to share and review.

### 🛡️ Error Handling

The application includes handling for:

- Invalid or unsupported datasets
- Missing numerical data
- LLM/API failures
- Temporary API availability issues
- Invalid analysis requests
- Edge cases in anomaly detection
